# Content: Showcase Page Builder

Structures a portfolio/showcase page that lets visitors scan multiple examples of work quickly, with a clear path to deeper detail on any specific project that interests them.

**When invoking**: On first use, confirm whether individual projects need dedicated case study pages or just showcase entries. On subsequent use, go straight to structuring.

## Scope

The gallery/index page structure. Not a single project's deep write-up (see **case-study-writer**).

## Structural Elements

| Element | Guidance |
|---|---|
| **Filterable categories** | If the portfolio spans multiple service types or industries, let visitors filter rather than scroll through everything |
| **Entry preview** | Image/thumbnail + one-line result or description per project — enough to decide whether to click through |
| **Consistent entry format** | Every entry should follow the same preview structure so the page reads as organized, not ad hoc |
| **Link to detail** | Entries with enough depth link out to a full **case-study-writer** page; simpler entries can stay showcase-only |

## Workflow

1. Confirm the categorization scheme (by service, industry, or project type) if the portfolio is large enough to need filtering.
2. Draft a consistent one-line preview format applied to every entry.
3. Identify which entries warrant a full case study link vs. staying showcase-only.
4. Build the filtering/navigation structure if needed.
