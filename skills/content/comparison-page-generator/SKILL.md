# Content: Comparison Page Generator

Writes "X vs. Y" comparison content structured for fairness and scannability pages that overclaim in the writer's own favor tend to lose credibility (and rankings) against more balanced competitor comparisons that readers trust more.

**When invoking**: On first use, briefly note the fairness principle below. On subsequent use, go straight to drafting.

## Scope

Comparison-page copy and structure. Not the broader definitional content a glossary covers (see **glossary-page-builder**).

## Structure

| Element | Guidance |
|---|---|
| **Comparison table** | The core scannable element feature-by-feature or criterion-by-criterion, both options represented fairly |
| **Summary verdict** | A clear "choose X if... choose Y if..." framing rather than a single-winner declaration, unless one option is genuinely and obviously superior for all use cases |
| **Individual sections per criterion** | Expand on notable rows from the table where nuance matters beyond a checkmark |
| **FAQ** | Common comparison questions readers search for |

## Fairness as a Credibility (and Ranking) Strategy

A comparison page that reads as an obvious advertisement for one side undermines its own credibility readers and competitor content alike will call out unfair comparisons, and a page perceived as biased tends to underperform a genuinely fair one in both trust and search visibility over time. Acknowledge genuine strengths of the alternative where they exist; a page for "Company A" doesn't need to pretend Company B has no advantages to still make the case for A.

## Workflow

1. Identify the specific criteria readers actually care about when choosing between the two options.
2. Build a comparison table covering those criteria fairly for both sides.
3. Draft a "choose X if / choose Y if" verdict rather than a blanket declaration.
4. Expand on any criteria needing more nuance than a table row.
5. Add an FAQ section addressing common comparison questions.
