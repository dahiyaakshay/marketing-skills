# Off-Page: Journalist Query Response Writer

Drafts responses to journalist source requests (HARO-style platforms or direct journalist queries) — the response needs to be immediately usable by a busy journalist, which means leading with the quotable answer, not a pitch about the respondent.

**When invoking**: On first use, confirm the specific query and the respondent's genuine expertise/credential. On subsequent use, go straight to drafting.

## Scope

Individual query response drafting. For broader digital PR pitching not tied to a specific incoming query, see **digital-pr-pitch-writer**.

## Structural Guidance

| Element | Guidance |
|---|---|
| **Direct answer first** | Lead with a specific, quotable answer to the exact question asked — journalists are scanning many responses quickly and will skip past a response that opens with a bio or company pitch before getting to the point |
| **Credential, brief** | One line establishing why this source is qualified to answer, placed after the answer, not before it |
| **Specificity over generality** | A response with a concrete example, number, or specific anecdote is far more usable and more likely to be selected than generic advice that could have come from anyone |
| **Respond quickly** | Journalist queries typically have tight deadlines — a well-crafted but late response is worthless |
| **No overt link request** | The byline/bio link is typically handled by the platform or by journalist convention — asking for a specific link placement can read as presumptuous and reduce selection likelihood |

## Workflow

1. Read the query carefully and identify the exact question being asked.
2. Draft a direct, specific, quotable answer as the opening line.
3. Add a brief one-line credential establishing relevant expertise.
4. Keep the total response concise — journalists reviewing many responses favor ones that are easy to scan and use.
5. Send promptly given the typically tight query deadlines.
